# Submission preparation and revision correspondence

Use these steps when the user asks for a submission-materials audit, a revision letter, or replies to reviewers. For the initial letter, use [journal cover letters](journal-cover-letter.md).

## Prepare the right package

For a journal shortlist, use the paper's subject, article type and intended readership. Candidate venues can come from relevant papers or journal matching tools. Check each candidate against its own scope and recent publications. If timing, access model, fees, waivers, institutional agreements or preprint policy matter, check the current journal sources and record the date. Recent receipt and acceptance dates can illustrate variability. They cannot establish a deadline for this manuscript.

Use the journal's current instructions for the article type and stage. Record each required item, its source or file, and any author information still needed. Possible items include the manuscript, figures, supplement, highlights, graphical abstract, cover letter, author roles, declarations and reviewer fields. Check whether initial submission accepts a combined PDF or requires editable sources, separate figures or a bibliography. Requirements can change at revision and acceptance.

Compare author order, affiliations, corresponding author, ORCID where required, title, abstract and keywords across the files and form. Match declarations and anonymization to the review model. If the system-generated review PDF is available, open it and check its actual pages, figure readability, equations, references, anonymous files and attachment categories. If only source files are available, report that scope. Record an existing manuscript ID when supplied. Provide the requested drafts or audit findings, leaving external submission to a separately authorized action.

## Read the editorial decision before drafting

A technical return generally asks for corrected files or metadata. An editorial rejection may concern fit or priority. External reviews assess the science. Use the actual decision letter for the requested route, deadline and revision files. Major and minor revisions require a response to the stated comments. An invitation to submit a new manuscript after rejection may have different identification and file requirements. Use the journal's review model, status and stated timelines for a requested inquiry. In single-anonymous, double-anonymous and open review, the identity and disclosure arrangements can differ by journal.

## Respond point by point

Retain each editor or reviewer comment and its numbering. For each substantive point, identify the issue, action already completed or proposed, supporting evidence, and actual manuscript location. Quote revised wording where useful. Supply section, page or line numbers only from the current version. Label planned changes as planned. A response written from only the reviews and an old draft should remain provisional until the new manuscript can be checked.

| Concern | Appropriate action |
|---|---|
| Unclear description | Supply the known detail, revise the wording, and identify where the clarification appears |
| Missing evidence central to the claim | Identify the needed analysis or experiment. Report actual results if available. If the evidence remains unavailable, reassess which claim can be sustained |
| Claim extends beyond tested conditions | Restrict it wherever it occurs or supply the additional supporting evidence. Check the title, abstract, discussion, conclusion and letter |
| Requested extension beyond the revised question | Explain the scientific reason for the chosen scope, what was tested and how the revised text marks the boundary. Check whether the extra evidence is essential even to the narrower claim |
| Disagreement | Address the scientific premise courteously using specific data, reasoning or checked literature. Account for each separate request in a compound comment |

Return the response, editor-facing revision letter or file checklist requested by the user. Use a final pass to compare each claimed change with the revised manuscript. After acceptance, proofs are a chance to check typesetting, author information, figures and equations. Raise a substantive scientific correction with the editor. Handle licensing, fees or waivers according to the actual journal instructions.
