# Journal submission cover letters

Draft or revise the letter a corresponding author addresses to a journal editor. Its purpose is to give the editor enough information to decide whether the manuscript fits the journal and merits review. Deliver the letter in English unless the user requests another language. Use the established editing depth for an existing letter.

## Gather the facts that change the letter

| Needed information | How to use it |
|---|---|
| Manuscript title, article type, author list and corresponding author | Copy the exact title, spelling, order and contact details from the manuscript. Use the requested author-list format |
| Journal, scope and reader | Use the official journal name. For journal-specific tailoring, check the current author instructions and scope, or use supplied guidance and identify it as such. Date the check in any preparation notes |
| Research question, principal finding, supporting evidence and conditions | Select the result that best answers the question. Preserve its comparator, design, population or material, and any condition needed for interpretation |
| Contribution and relationship to existing work | Explain what a reader can now understand, compare or do. A claim of priority or a comparison with a journal article needs a checked basis |
| Author declarations and submission stage | Use the authors' actual statements and the journal's requirements. Distinguish a first submission from a revision with a manuscript ID and a response to reviewers |

Draft the supported portions even when information is missing. If the journal is unknown, use a visible journal placeholder and defer the fit sentence. Use a neutral salutation such as *Dear Editor,* when the editor's name or role is unverified. Keep consequential questions short and separate from clean letter prose. If a required item is unresolved, label the deliverable a draft and identify exactly what the author needs to supply.

## Build the letter

1. **Identify the submission.** Use the intended submission date if supplied, the correct journal and recipient, then the manuscript title, article type and authors as needed. If a date, identifier or contact is missing, leave a descriptive placeholder where the format requires it.
2. **Explain the scientific case.** Introduce the unresolved question in a sentence a nonspecialist editor can follow. Give the main result and the evidence that supports it. Explain the advance relative to the relevant prior understanding. Distinguish a measured result, a simulation prediction, and a proposed mechanism. Keep scientific scope intact when shortening.
3. **Explain the fit.** Connect one specific finding to a topic in the supplied or verified scope and to what the journal's readers will gain. Mention a recent paper in the journal only if the comparison is useful and its content has been checked. A claim about the journal's prestige does little to explain fit.
4. **State applicable declarations.** Include only statements supported by author-supplied facts, in the location the journal requests. Use the checks below for missing or conflicting information.
5. **Close.** Thank the editor for considering the manuscript and sign with the corresponding author's confirmed name, affiliation and contact email. Add other contact details when required. Keep the letter short enough for a quick editorial reading. Follow the journal's format, length and upload or text-field requirements. Use a readable standard typeface if producing a file.

For a revision letter, use the verified manuscript ID and decision, identify the principal changes actually made, and refer the editor to the point-by-point response. Keep detailed replies in that separate document. See [submission and revision](submission-and-revision.md).

## Handle declarations fact by fact

| Topic | Decision |
|---|---|
| Originality and concurrent consideration | Check publication history and current consideration separately. Report preprints, related submissions or overlapping publications when relevant, with an identifier if supplied. Check the journal's preprint policy before wording the declaration |
| Author approval and interests | Confirm final-version approval and competing interests independently. Report disclosed interests accurately. Missing information requires an author query |
| Ethics | Include the applicable approval, committee, identifier, consent or exemption only from supplied facts. Query an unspecified approval when it is required |
| AI assistance | Identify the tool and version when known, actual use, and human checks the author confirms. Separate language checking, substantive rewriting and research uses such as code generation. Describe research methods and verification where they belong in the manuscript. Check the journal's disclosure rules |
| Data availability | For public data, verify the repository, identifier, accessible files and scope when possible. For controlled access, state the owner, conditions and contact route. For unavailable data, give the supplied restriction. Make the letter, manuscript and submission fields agree |
| Reviewer recommendations or exclusions | Include only when relevant to the instructions. Use confirmed identities, affiliations, contact details and expertise. Check known conflicts. Give a brief factual reason for an exclusion in the appropriate field |

Use the location specified for each declaration. A journal may ask for a separate funding, contribution, competing-interest or data statement even when the letter briefly mentions the same facts. For an unknown fact, a draft note such as *Author query: confirm whether all authors approved this version* is preferable to a signed assertion.

## Worked editorial decision

Invented teaching scenario. In a simulation study, two boundary conditions gave different estimates of peak load for the same specimen geometry. The journal scope supplied for this exercise includes computational solid mechanics. A concise pitch could read:

> Our simulations show that changing the support condition alters the predicted peak load for this specimen geometry. The comparison helps readers of computational solid mechanics distinguish a boundary-condition effect from a change in the material model.

This formulation identifies both the result and its use to a reader. Before applying it to a real manuscript, trace the comparison and the claimed distinction to that manuscript's evidence. Write a complete letter from the user's facts, with the declarations checked separately.

## Final read

Verify the title, names, journal, article type, date, contact information and any manuscript ID. Compare each scientific claim with the abstract and supporting result. Re-read the fit sentence with the journal name removed. If it could describe almost any journal, identify the actual audience and scientific connection. Surface outstanding author decisions. Preparing a letter delivers a reviewable draft. Sending or submitting it requires a separate user instruction.
